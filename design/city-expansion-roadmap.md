## 1. 分级模型

### S 级 · 旗舰城市（内容最全，首发）
每城内容包：城市 + 国家 + 5–8 景点 + 2–3 路线 + 3–5 攻略 + best-time + **route-plan/budget 路书（1–2 部）** + seasonal（如适用）。

| 城市 | 国家 slug | 城市 slug | 理由 |
|---|---|---|---|
| 东京（已有） | japan | tokyo | ✅ 已全量（含路书/预算/季节） |
| 北京（已有） | china | beijing | ✅ 已全量 |
| 巴黎 | france | paris | 欧洲门户、高搜索量 |

| 纽约 | usa | new-york | 美洲门户 |

### B 级 · 区域旅游城市（内容精简）
每城内容包：城市 + 国家（如有）+ 3–5 景点 + 1–2 路线 + 2 攻略 + best-time。

例：大阪、奈良、神户（日本）；杭州、苏州、成都、西安、广州、深圳、香港、澳门（中国）；清迈（泰国）；河内、胡志明（越南）；巴厘岛（印尼）；台北（中国台湾）；洛杉矶、旧金山、拉斯维加斯、波士顿、西雅图（美国）；柏林、慕尼黑、阿姆斯特丹、维也纳、苏黎世、里斯本、雅典、伊斯坦布尔（欧洲）；开罗（埃及）；墨西哥城（墨西哥）；里约热内卢（巴西）；圣保罗、布宜诺斯艾利斯（南美）等。

### C 级 · 补充城市（最低限度）
每城内容包：城市 + 3 景点 + 1 路线 + 1 攻略 + best-time（城市 JSON + 少量子实体）。

例：札幌、福冈、名古屋（日本）；天津、青岛、厦门、三亚（中国）；布鲁塞尔、哥本哈根、奥斯陆、斯德哥尔摩、赫尔辛基、爱丁堡、都柏林（欧洲）；珀斯、墨尔本、奥克兰（大洋洲）；吉隆坡、雅加达、马尼拉（东南亚）；华盛顿、芝加哥、迈阿密（美国）；卡萨布兰卡、内罗毕、开普敦（非洲）等。

## 3. 生产顺序建议

1. **批次 1（S 级，3 城）**：巴黎 → 伦敦 → 纽约（+ 3 国家 JSON），验证完整内容包与跨国家基建。
2. **批次 2（A 级，7 城）**：京都、上海、首尔、新加坡、曼谷、罗马、巴塞罗那（复用已有 japan/china 国家；+5 国家）。
3. **批次 3（B 级，~20 城）**：区域旅游城市批量生产（模板化，内容包精简）。
4. **批次 4（C 级 + 长尾）**：填充至 100 城。

**每批验收**：build 页数递增、新城市 Hub 各模块就位、首页/目录页自动聚合、sitemap 自动收录、无空页、无 `[object Object]`。

## 4. 风险与容量预估

- **页面数**：100 城 ×（1 城市页 + ~6 子实体页）≈ 700–800 页 + 目录页，SSG 静态构建无压力。
- **图片**：100 城 × 2–3 图 ≈ 200–300 对象（L2 本地 / L3 R2，见 image-system-v2）。
- **内容工作量**：S 级每城 ~10 文件，A 级 ~7，B 级 ~5，C 级 ~4——总量可控，模板可复用。
- **风险**：内容准确性（事实/时区/货币）需人工校验；国家模型先行（缺国家则城市无法挂载）；`related` 引用完整性。
